# Skill: API Security & Input Validation

## Objective
Đảm bảo tất cả endpoint nhận dữ liệu từ cảm biến / người dùng được xác thực và làm sạch đúng chuẩn trước khi xử lý.

## Rules
- Mọi dữ liệu tọa độ (lat, lng) phải nằm trong phạm vi hợp lệ.
- Kiểm tra tính xác thực của dữ liệu đo từ các trạm quan trắc IoT.
