# Changelog: feat-realtime-weather

## [1.0.0] - 2026-09-27
### Added
- Tích hợp dữ liệu thời tiết trực tiếp từ Open-Meteo Weather API (nhiệt độ, lượng mưa, độ ẩm, sức gió, mã thời tiết WMO).
- Cơ chế tự động cập nhật thời tiết theo vị trí GPS hoặc khi chọn tỉnh thành.
- Đánh giá nguy cơ ngập lụt theo ngưỡng mưa thời gian thực (>25 mm/h).
- Tích hợp lớp Radar Mây Mưa vệ tinh trực quan (RainViewer radar overlay).
